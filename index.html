تطبيقك تقيل ليه؟

حط لينك أي repo Flutter على GitHub. الصفحة بتقرا شجرة الملفات و pubspec.yaml وكود lib/، وتقولك أنهي صور تقيلة أو محتاجة WebP، وأنهي assets وخطوط وباكدجات محدش بيستخدمها. وتحت تقدر ترمي ملف --analyze-size وتشوف الـ APK رايح فين. كله بيحصل في المتصفح بتاعك، مفيش server.

الـ repo فيه أكتر من مشروع. اختار واحد:

الصور

الـ assets

من flutter: assets: و fonts: في pubspec، ومقارنتها بالملفات الموجودة فعلًا وبالـ strings في lib/.

الباكدجات

باكدج في pubspec ومفيش ولا ملف في lib/ أو bin/ أو test/ بيعمله import.

حجم الـ APK / IPA

ابني نسخة release بالأمر ده، وفي الآخر Flutter بيطبعلك مكان ملف JSON (غالبًا ~/.flutter-devtools/apk-code-size-analysis_01.json). ارميه هنا — الملف مش بيتبعت لأي حتة.

flutter build apk --analyze-size --target-platform android-arm64

وفيه كمان flutter build appbundle --analyze-size --target-platform android-arm64 و flutter build ios --analyze-size.

(أرقام توضيحية)

البيانات من GitHub مباشرة من المتصفح. التقديرات تقريبية. المصدر على GitHub

الإعدادات

محتاجه بس للـ repos الـ private، أو لو GitHub وقفك بعد 60 طلب في الساعة. اعمل fine-grained token صلاحيته Contents: Read-only بس. الـ token بيروح لـ api.github.com وبس، ونفس الـ token بيشتغل في Deps Watch.

حدود الصور

كل صورة بنقيس أبعادها بتتحمّل من GitHub (من غير token مش بتتحسب من الـ 60 طلب).
